# BoardForge Manufacturability Risk

Passing DRC is necessary but not enough. BoardForge separates PCB fab readiness from assembly and compliance readiness.

The risk report calls out trace/space, via, copper-edge, hole, solder mask, silkscreen, outline, mounting, BOM/CPL, sourcing, and compliance-review risks when they are visible in local artifacts.

Supplier stock remains `NOT_CHECKED` until API keys are configured.
