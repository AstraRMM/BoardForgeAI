# BoardForge Demo Flow

1. Open the web dashboard.
2. Show readiness dashboard and fixture proofs.
3. Import an existing KiCad project into a sandbox.
4. Show source hash before/after.
5. Run validation.
6. Run dirty-to-clean repair.
7. Export manufacturing ZIP when DRC/ERC/unconnected gates are clean.
8. Open KiCad plugin status.
9. Show CLI replay command.
10. Run PoE REV_D sourcing verification.
11. Explain `PCB_FAB_READY` versus `ASSEMBLY_READY_VERIFIED`.

No cloud execution is implied. The dashboard reads local BoardForge artifacts.
