# BoardForge Project Health Score

The project health score summarizes whether a board is ready to keep routing, ready for PCB fabrication, blocked, or ready for human review.

Inputs include DRC, ERC, shorts, unconnected items, manufacturing package status, sourcing verification, pin-map checks, routeability, outline validity, and review risks.

Labels:

- Needs Work
- Routable
- PCB Fab Ready
- Assembly Not Verified
- Ready for Review
- Blocked
