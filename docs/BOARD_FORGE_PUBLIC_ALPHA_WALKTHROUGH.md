# BoardForge Public Alpha Walkthrough

1. Start the installed local BoardForge engine.
2. Open the live BoardForge website.
3. Pair the browser to the local engine with a one-time code.
4. Run first-run setup checks.
5. Launch one-click demo.
6. Create or import a board.
7. Generate variants.
8. Run Make Manufacturable.
9. Review health/risk/routeability/diff reports.
10. Export manufacturing only if validation is clean.
11. Publish to dashboard only with explicit confirmation.
