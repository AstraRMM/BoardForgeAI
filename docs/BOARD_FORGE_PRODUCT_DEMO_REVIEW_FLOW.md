# BoardForge Product Demo Review Flow

Run:

```powershell
npm run boardforge:product-demo-review
```

The demo creates `BF-PRODUCT-DEMO-REVIEW-01_REV_A`, runs the odd-shape local candidate flow, exports a manufacturing ZIP, and writes review, health, risk, routeability, diff, blocker, preview, and applied-lessons artifacts.

The board remains a local candidate unless explicitly published.
