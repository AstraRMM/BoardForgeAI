# BoardForge Web Dashboard Demo

Start locally:

```powershell
.\tools\boardforge-launcher\BoardForge_Start_Local_Alpha.ps1
```

Open:

`http://localhost:3000/dashboard`

## What To Show

- Dashboard: published projects only, readiness summary, local engine artifact notice.
- Projects: project cards with DRC/ERC, manufacturing readiness, sourcing status, and ZIP/report paths.
- Project detail: board brief, approval state, local candidate state, publish controls, CLI replay, and KiCad action log.
- Readiness: evidence-backed alpha score and exact external blockers.
- Downloads: manufacturing ZIP/report paths.
- New board: prompt-to-brief flow, not fake cloud execution.
- Upload KiCad: sandbox import and source-hash safety model.

Every action is labeled as local engine/artifact-backed when it is not a live hosted cloud run.

The web dashboard is local-engine-backed. It shows artifacts generated by the local BoardForge engine.

It should show:

- source and sandbox paths
- source hash guard result
- DRC/ERC before and after
- repair transactions
- manufacturing readiness
- sourcing status
- ZIP/report paths
- CLI replay command

No fake cloud execution is claimed.
