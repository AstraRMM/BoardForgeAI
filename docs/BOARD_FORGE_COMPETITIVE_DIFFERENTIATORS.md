# BoardForge Competitive Differentiators

BoardForge does not only generate PCB files.

It creates, routes, validates, repairs, explains, grades, compares, packages, and documents local KiCad projects.

Key differentiators:

- Localhost job queue for real app actions
- BoardForge Engineering Review
- Project health score
- Manufacturability risk beyond DRC
- Routeability explanations
- Board diff and revision confidence
- Preview artifacts and project cards
- Exact blocker reports instead of vague failure states
- Visible solution-library lessons
- Strict PCB fab vs assembly readiness separation
- Live website connected to an installed local BoardForge engine bridge
- Local-first source protection with approved-only publish
