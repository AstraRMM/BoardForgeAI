# BoardForge Competitive Differentiators

BoardForge differentiates itself by treating PCB generation as an engineering workflow, not a single prompt-to-image moment.

## Differentiators

- KiCad-native project output instead of proprietary-only previews.
- Local-first source protection for imported customer projects.
- Custom board generator with routeability and Edge.Cuts intent.
- Make Manufacturable workflow for DRC/ERC, placement, routing, and export blockers.
- Make Sourcable workflow for BOM risk, live supplier evidence, and alternatives.
- Live DigiKey and Mouser sourcing where configured through local credentials.
- Evidence dashboard with tests, reports, artifacts, and limitations.
- Public-alpha launch gate that refuses fake readiness.
- Approved-only publish and demo artifact authenticity checks.

## Tone Rule

Do not publicly attack competitors by name. The public message should be calm, technical, and evidence-backed:

BoardForge checks, sources, repairs, explains, and packages KiCad projects. It does not merely produce a board-looking output.

## Honest Alpha Moat

The moat is not claiming perfection. The moat is showing what passed, what failed, what is blocked, and what needs engineer review before fabrication or assembly.
