# BoardForge Pricing Draft

No free tier for production use. The product handles manufacturing files and should be positioned as serious engineering software.

## Starter Annual

- Solo builder
- Local KiCad engine
- Board generation, routing, validation reports
- Synthetic fixtures and simple manufacturing packages

## Pro Annual

- Advanced board workflows
- Router ensemble
- Exact ratsnest finishing
- Part verification reports
- Manufacturing package validation

## Team Annual

- Shared projects
- Review workflows
- Regression fixture history
- Dashboard and artifact management

## Enterprise / Custom

- Private deployments
- Vendor policy controls
- Custom sourcing integrations
- NDA/security review
- Dedicated manufacturing workflows
## Alpha Packaging Notes

Paid tiers should gate premium local-engine actions such as project creation, repair, export, sourcing verification, and dashboard publishing. Supplier verification remains unavailable until users configure their own supplier API keys or BoardForge offers hosted provider credentials.
